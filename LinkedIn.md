# LinkedIn Post Draft (Conversion-Optimized, English)

Construction teams do not lose money because they lack documents.  
They lose money because evidence is disconnected from Change Orders.

I built **SiteScribe** to solve that exact gap.

SiteScribe is an open-source platform that turns:
**site logs + RFIs + plan revisions + contracts + photos**  
into:
**traceable, audit-ready Change Order workflows**.

## What this enables

- Evidence-first project records in one place
- Signal detection from field evidence
- Event triage for PM workflows
- CO draft generation (template + optional AI)
- Structured CO editing with line items and comments
- Audit log and approval visibility
- Export pipeline: PDF + ZIP + SHA-256 manifest
- Scheduled exports + webhook delivery

## End-to-end flow

**Evidence Upload -> Signal Detection -> Event Triage -> CO Draft -> CO Review/Approval -> Export**

## Who it is for

- General contractors
- Project managers
- Subcontractor coordination teams
- Construction-tech and AI-ops builders
